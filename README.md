# Quick Start | 快速上手 🚀
- **EN - Mobile iOS Controls**
  - **Movement**: Virtual joystick (bottom left) or tilt device
  - **Attack**: Tap anywhere on screen for normal attack
  - **Ultimate**: Two-finger tap for ultimate skill  
  - **Aiming**: Drag finger from attack button toward target
  - **Menu**: Three-finger tap or pause button
  - **Login Scene**: Cyberpunk-themed main menu with neon UI
  - **Team Lobby**: Holographic character selection
  - **Neon Data Heist**: Futuristic server room environment
  - **Corporate Vault**: High-tech office tower setting
  - **Character Switch**: In-game character selection with anime portraits
  - **AI Toggle**: Settings menu → Gameplay → Enable/Disable AI

- **CN - iOS 移动端操控**
  - **角色移动**: 虚拟摇杆（左下角）或倾斜设备控制
  - **普通攻击**: 屏幕单指点击
  - **终极技能**: 双指点击释放大招
  - **攻击瞄准**: 从攻击按钮向目标拖拽
  - **菜单**: 三指点击或暂停按钮
  - **登录场景**: 赛博朋克主题霓虹UI界面
  - **队伍大厅**: 全息角色选择界面
  - **霓虹数据劫掠**: 未来主义服务器机房环境
  - **企业金库**: 高科技办公大楼场景
  - **切换英雄**: 游戏内动漫风格角色选择界面
  - **AI开关**: 设置菜单 → 游戏性 → 启用/禁用AI
